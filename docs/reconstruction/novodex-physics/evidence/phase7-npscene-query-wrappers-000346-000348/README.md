Base commit: `49f40184c98e5915a1c88562226b61ed1c347a1e`. Oracle `NxPhysics.dll` SHA-256: `4b7db3e126735c576f79fe5666e6fa661de9724b2a78808bb0924325ac79602c`. The registered `NxPhysicsSimulationTests` fixture calls both public query wrappers for empty and populated scenes under broadphase selectors 0, 1, and 2. Baseline staged-pair output is exact (`stdout_delta=0`, both exits zero, exact stderr); see `baseline.log`.

`phys_fn_000346` (`NpScene::getSceneStats`, RVA `0x0000cc60`) was mutated in a throwaway archive by replacing only `return stats;` with `return 0;`. The candidate then reports `present=0` and sentinel stats for the queried scenes. The staged-pair differential catches it with `stdout_delta=12`, both exits zero, and exact stderr. The one-line patch is `phys_fn_000346.patch`; mutant and restored excerpts are in the matching logs. Mutant candidate DLL SHA-256: `246b2324fc08f5161460e3901931675fec4906a343ba9b4e21de6e3089f108ac`; restored control SHA-256: `4809abf108117059118c778553fb0e4771a8e8a7ecde51baf78444b82d4f3053`.

The differential catches it with `stdout_delta=6`, both exits zero, and exact stderr. The one-line patch is `phys_fn_000348.patch`; its mutant and restored excerpts are in the matching logs. Each restored result is exact. These are isolated throwaway mutations; production source and public headers are unchanged.
