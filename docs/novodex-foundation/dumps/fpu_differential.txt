Root cause
Oracle setter RVAs 0x000040d0..0x00004180 call the legacy CRT control helper with precision masks 0x30000, rounding mask 0x300, and exception mask 0x8001f. Runtime state shows that helper mutates only x87: all setters leave MXCSR byte-for-byte unchanged. The modern rebuilt CRT _controlfp mutates MXCSR rounding/masks too. Oracle false exception state retains only x87 denormal masked (CW & 0x3f == 0x02).

Minimal patch
The Win32 wrappers now perform masked fnstcw/fldcw updates directly: precision CW mask 0x0300; rounding CW mask 0x0c00; exception CW mask 0x003f with values true=0x003f and false=0x0002. The conversion algorithms are unchanged.
