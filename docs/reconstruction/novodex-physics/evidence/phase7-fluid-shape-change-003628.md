# Fluid shape-change dirty refresh — `phys_fn_003628`

`phys_fn_003628` sets the enabled FluidManager shape-change dirty byte at `manager+0x28` when a static shape is added or removed. Dynamic actor add/remove leaves that byte clear. The existing helper in `Physics/src/Scene.cpp` already matched the oracle; the defect was that the static actor registration path in `nxSceneAddActorObject` returned without invoking it. The path now calls `nxFluidManagerShapeChanged` after registering the static object with the pruner.
