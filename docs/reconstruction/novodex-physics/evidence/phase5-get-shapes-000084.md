# Actor public-shape-array getter (`phys_fn_000084`)

Oracle RVA `0x2d30` acquires the actor read lock, calls helper RVA `0x1540` on the inner actor, releases the lock, and returns the helper result. The helper returns null when no shape root exists, the pointer stored at root+`0xf0` for kind-5 group roots, and root+`0x9c` for a single root. Candidate `NpActorVtable::getShapes` implements those branches at `Physics/src/NpActor.cpp:1566`. The Win32 Release map resolves `?getShapes@NpActorVtable@@UBEPAPAVNxShape@@XZ` to candidate RVA `0x0002ffa0` in `NpActor.obj`.

`NxPhysicsActorShapeMutationTests` asserts that the public single-root array equals root+`0x9c` and that a group returns the public-handle array pointer stored at root+`0xf0`. The untouched staged differential passed with `stdout_delta=0`; candidate DLL SHA-256 `777ed3ed4493f6e452fa17befd250a4f956d96cb2bfb1e459c9ac7e450ebe428`.

The two return arms were falsified separately. Returning single-root root+`0xa0` instead of root+`0x9c` failed `single-root public shape array mismatch` (`oracle_exit=0`, `candidate_exit=1`, `stdout_delta=311`; mutant SHA-256 `242d80adf80f913c74473a9cd4460260a4ffe48b1d7261f1d745e33a7fc5f3eb`). Returning the kind-5 root+`0xe0` child-array address instead of the public array pointer stored at root+`0xf0` failed `group public shape array mismatch` (`oracle_exit=0`, `candidate_exit=1`, `stdout_delta=308`; mutant SHA-256 `eaaf6eeac2fb2243ef3c303b648b8840c45640f8dea96ab5b17906965ce9964d`). Restoring both returns produced an exact staged differential (`oracle_exit=0`, `candidate_exit=0`, `stdout_delta=0`, exact stderr); restored candidate SHA-256 `3ef8a1129c9e8d969eb00118c2c031acfb6a0fce91cf1601e19b180e1a090266`. The pinned oracle SHA-256 was `4b7db3e126735c576f79fe5666e6fa661de9724b2a78808bb0924325ac79602c` in all runs.
