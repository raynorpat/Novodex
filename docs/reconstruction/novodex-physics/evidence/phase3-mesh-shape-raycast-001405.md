# MESH shape raycast (`phys_fn_001405`)

`phys_fn_001405` is the MESH shape's internal vtable slot 5 at RVA `0x00029230`. The implementation in `Physics/src/ShapeRaycast.cpp` queries the owned OPCODE model with the shape transform and maximum distance, selects the closest face, then writes the world-space impact, face index (using the optional face remap when present), barycentrics, distance, and optional interpolated vertex normal. `Physics/src/ObjectModel.cpp` now routes the MESH slot to this method; the debug slot remains unsupported.

The registered `NxPhysicsSceneRaycastTests` fixture uses the same triangle mesh for front-face hit, omitted normal, too-short maximum distance, translated hit, miss, backface rejection, and a rotated hit. Oracle and candidate outputs match byte-for-byte (`oracle_exit=0`, `candidate_exit=0`, `stdout_delta=0`, exact stderr). The mesh-hit markers pin face IDs, barycentrics, world impacts, normals, flags, and distance words.

A candidate-only no-hit mutation at the new method was rejected by the differential (`stdout_delta=8`); it caused the mesh rays to select a plane or miss and removed the registered mesh markers. The restored control passed with `stdout_delta=0`. The executable raycast target is registered in Phases 4, 5, and 7, and each coverage floor was raised to include its mesh assertions. The Phase 3 closure ledger still records this row as deferred; this evidence records the implementation and behavioral checks while the broader row-closure bookkeeping remains open.

The normal fixture now includes a slanted face (the third triangle has one vertex at y=1). It exercises a non-axis-aligned interpolated normal: the oracle and candidate both emit the exact normal words `be785b42.3f785b42.00000000`, with impact `(39, 0.25, -1)` and distance `4.75`. IDA disassembly of `0x10029597..0x100295e2` shows the oracle uses x87 `fsqrt`, checks against zero, computes the reciprocal in the x87 stack, and rounds each component on its `fstp dword` store. The observed differential resolves the review concern for this fixture; no precision change was needed.
