## Method

**Hybrid unit gate:** Rebuild `NxFoundation.dll` from Novodex `Foundation/src` as the default candidate per cluster (`c_sdk` … `c_misc`). For each cluster, compare against the binary oracle (exports, vtable layout, key sizes, selected Capstone/Kawaiidra behavior). **KEEP** only when the unit gate passes. Failing KEEP becomes **PATCH** or **REPLACE** with evidence recorded in `evidence.md` and `inventory.json`.

Reconstruction gates (all pass at the Task 9 boundary):

| Gate | Meaning |
|---|---|
| `export_abi` | All 134 required oracle names are present; six accepted extras remain; the missing-name gate passes |
| `structural` | Inventoried types / vtables / key object sizes match oracle |
| `selected_behavior` | Capstone-backed KEEP/PATCH/REPLACE on non-trivial units |
| `consumer_smoke` | Unreal_3 loads rebuilt DLL and initializes Foundation/Novodex path |

Public UE3 headers are immutable after transplant; fix implementation and private headers only.
